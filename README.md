# Terminal-Launcher (Android 11 / API 30)

Generated by Terminal-Launcher.

## Android 11 Compatibility Included
- **Package Visibility (API 30)**: `QUERY_ALL_PACKAGES` declared in `AndroidManifest.xml` so `AppIndexManager` can list and launch every installed app.
- **Scoped Storage**: Configured to store Terminal-Launcher config inside `Context.getExternalFilesDir(null)` without needing broad storage exemptions.
- **Wi-Fi Toggle**: Uses `Settings.Panel.ACTION_WIFI` (required on Android 10/11 where apps cannot silently toggle the Wi-Fi radio).
- **Keyboard & Edge-to-Edge**: Uses `WindowCompat.setDecorFitsSystemWindows` + `WindowInsetsCompat.Type.ime()` for smooth Android 11 soft keyboard docking.

## Option A: Build Cloud APK via GitHub Actions (No PC / Android Studio Needed)
1. Unzip this folder and push its contents (including `.github/workflows/build.yml`) to a GitHub repository.
2. Open the **Actions** tab on GitHub — the **Build Android 11 Debug APK** workflow runs automatically (or click **Run workflow**).
3. Once finished, download the `terminal-launcher-android11-debug-apk` artifact directly onto your Android 11 phone and install the APK.

## Option B: Build Locally with Android Studio / ADB
1. Open this folder in **Android Studio** (Hedgehog or newer).
2. Let Gradle sync SDK 30 platform tools.
3. Run `gradle assembleDebug` (or click **Build → Build APK(s)**).
4. Install on your Android 11 phone:
   `adb install -r app/build/outputs/apk/debug/app-debug.apk`
5. Press the Home button and select **Terminal-Launcher** as your default Home app.
